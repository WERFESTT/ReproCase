Переносите эту папку целиком, включая historical_vendor и все файлы .py/.json.
Это не одиночный самостоятельный тест: рядом закреплены его исходники и лицензии.
Нужен CPython 3.14 с обычной стандартной библиотекой; GUI, Hypothesis, ключ и сеть для повтора не нужны.
python3 -I -S -B /путь/к/этой/папке/test_prepared.py --version before
python3 -I -S -B /путь/к/этой/папке/test_prepared.py --version after
До: ожидается один assertion-провал, exit 1; после: успех, exit 0. Ошибка комплекта: exit 2.
Запускайте команды отдельно, без &&. Не создавайте __pycache__ внутри комплекта.
Содержимое не ищется в старом проекте/cwd/PYTHONPATH; запуск требует -I -S.
Хеши обнаруживают изменение относительно этого доверенного теста; это не подпись автора
и не защита от согласованной замены самого теста и всех хешей.
Сторонние лицензии сохранены. Лицензия нового кода владельцем ещё не выбрана.
