## Что показано

На двух исторических дефектах получены воспроизводимые переносимые тесты. Наблюдаемого преимущества проверок модели перед соответствующими ручными условиями нет. Выбор области входных данных влияет на обнаружение дефекта; два специально построенных результата выявляют неполноту проверок возвращаемых значений.

Сохранены шесть ответов модели и 12 переносимых тестов новой серии. Отдельный локальный эксперимент содержит 120 поисков и 36 экспортированных тестов. Старые незавершённые опыты остаются отдельными записями и не считаются завершённой частью новой серии.

## Повторить проверку

Из корня репозитория:

```bash
python3 -B research/2026-11-07/verify_public.py --replay
python3 -B research/2026-11-07/test_research.py
```

Ожидаются 100 совпавших исходов: 24 для новой серии, 72 для локального эксперимента и четыре для прежних примеров. Это повторение сохранённых тестов, а не новые независимые наблюдения. Запросы модели не выполняются.

Папка `2026-11-07` хранит подготовленный исследовательский пакет без изменения байтов, включая собственный снимок исходников. Дальнейшая разработка ведётся в корне репозитория. Технические идентификаторы в исторических записях описывают выполненный опыт.
