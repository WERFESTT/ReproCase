## Самый короткий путь

Склонируйте или скачайте весь репозиторий в новую папку. Сохраните структуру и все файлы из манифеста. Указанная ниже точка входа сверяет хеши перед загрузкой модулей приложения. Не накладывайте архив поверх другой установки.

Перейдите в распакованную папку и выполните:

```bash
python3 -I -B judge.py demo
```

Это повтор двух выбранных сохранённых свидетельств: раннего успешного реального ответа и отдельного офлайн-ремонта второй попытки последующей серии. Для каждого ожидается assertion-провал на версии before и успех на after, без ошибок контура. Общий код завершения команды — 0, когда все четыре ожидаемых исхода совпали. Результат записывается в review-output/demo.json; исходные свидетельства не перезаписываются. Новый запрос модели не выполняется.

Откройте index.html файловым менеджером для сводки и ссылок. Сервер и интернет не нужны. Исходные JSON-отчёты скопированы отдельно с явной пометкой DERIVED_REDACTED_COPY: только строки первоначального пути заменены на SOURCE_PROJECT, добавлены хеш оригинала и описание преобразования. Команды внутри этих исторических записей — данные, не инструкции запуска. Свидетельства witness.json и закреплённые исходники replay не менялись.

## Окно

```bash
python3 -I -B judge.py gui
```

Это прежнее окно: три учебных случая, локальные проверки, подбор входа, тема, копирование, предпросмотр диагностического запроса. Заголовок отмечает OFFLINE_REVIEW/OFFLINE. Три сетевые кнопки отключены; ключ не запрашивается. Сохранённый настоящий ответ открывается отдельно через index.html — окно не умеет загружать его как новый сеанс. Не принимайте текущие учебные значения за исторический результат.

Команды работают и из другого cwd: замените judge.py полным путём к НОВОЙ папке. Исходная папка проекта не нужна. Для отображения нужен рабочий графический сеанс и Tkinter; системные настройки не меняются. При отсутствии Tk используйте demo и HTML. Проверка виджетов выполняется через gui --hidden-check; это не визуальная оценка оформления.

## Зависимости и границы

| Режим | Что требуется |
| --- | --- |
| Прочитать index.html/JSON | Браузер или текстовый редактор; Python не нужен |
| demo, verify, закреплённый replay | CPython 3.14 со стандартной библиотекой; без Hypothesis, Tk, ключа и сети |
| gui | То же + установленный Tkinter и графический сеанс; Hypothesis не нужен для учебных проверок |
| pilot, synthetic | То же + Hypothesis 6.170.9 и sortedcontainers 2.4.0 в отдельном venv |

Проверенная платформа — CPython 3.14.4, Linux x86_64. Сохранённое колесо Hypothesis относится к CPython 3.14/Linux x86_64, не к произвольной ОС. Python/системный Tk в комплект не входят; мы не обещаем автономный бинарник. Для другой платформы зависимости и поведение нужно проверять отдельно.

Для полного прежнего исторического пилота, из корня комплекта:

```bash
python3 -m venv .venv
.venv/bin/python -I -m pip --isolated --disable-pip-version-check install --no-index --no-deps --no-cache-dir --require-hashes -r requirements-pilot.txt
.venv/bin/python -I -B judge.py pilot
```

Колёса уже находятся в app/historical_vendor/wheels, хеши закреплены. Установка не обращается к реестру и не меняет глобальное окружение. pilot сравнивает обычный поиск и Hypothesis на двух известных исторических дефектах; модель в нём не участвует. Дополнительная команда `.venv/bin/python -I -B judge.py synthetic` запускает прежний маршрут с явно искусственными ответами. Это проверка программы, не результат NVIDIA. Новые отчёты этих команд создаются в app/outputs.

## Что доказывают выбранные данные

- Первый успешный запрос: 1551 входной + 195 выходных токенов; два файла тестов / четыре исполнения, по 767 исполнений у свойства модели и ручного контроля. В комплекте выбран один из этих тестов — Hypothesis.
- Отдельная серия: 2 запроса из плана 6. Первое допустимое свойство в узкой области не дало контрпримера. Второе дало находки, но исходный экспорт упал из-за смешения версий локального кода. Четыре позиции не запускались; исходный результат остаётся 0/6 подтверждённых экспортов. 3102 входных + 513 выходных токенов. Неуспехи не исключены.
- После исправления обвязки второе сохранённое предложение повторили офлайн. Выбранный здесь boundary_grid-тест подтверждает этот ремонт; это не новый ответ модели и не успешное завершение первоначальной серии.

Оценки расходов в производных отчётах не являются счетами поставщика или денежными гарантиями. Словарь свойств, смысловая приёмка и выбор известных ошибок подготовлены вручную. Автономность, работа с произвольными проектами, превосходство над Hypothesis, экономия труда и статистическая надёжность не доказаны. Отсутствие контрпримера не доказывает исправность.

## Состав и целостность

MANIFEST.json перечисляет каждый включённый файл, размер, SHA256 и происхождение выбранных копий. Состав: app — явный список исходников приложения, планов и примеров; historical_vendor — закреплённые исходники/лицензии и два колеса; evidence — два выбранных replay-комплекта и три производные записи; judge.py, index.html, RU/EN инструкции, уведомления. Полные outputs, venv, ключи, пользовательская настройка темы и промежуточные журналы не включены.

Проверка без запуска расчёта: `python3 -I -B judge.py verify`. Вход проверяет хеши до импорта, использует только закреплённые модули приложения и отключает сетевые действия этого маршрута. Флаги -I обязательны; cwd/PYTHONPATH не выбирают импортируемый код. Запускайте только документированную точку входа. Это не универсальная песочница для недоверенного Python. Хеши не удостоверяют автора и не защищают от согласованной замены манифеста, загрузчика и содержимого.

Это экспериментальный исходный релиз. Польза модели в общем случае не доказана. Видео остаётся черновиком для проверки: публичная ссылка YouTube и подача заявки не заявляются. Любые будущие обращения к модели и подача остаются отдельными действиями владельца.
