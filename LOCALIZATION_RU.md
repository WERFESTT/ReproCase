# Русский и английский интерфейс

Справа в заголовке окна, рядом с темой, находится **«Язык / Language: RU / EN»**. Переключатель меняет кнопки, вкладки, меню, статусы, пояснения и уже показанные результаты. Он не запускает расчёт, не отправляет запрос и не стирает результат. Выбор хранится только как `{"language":"en"}` или `{"language":"ru"}` в `language_settings.json` рядом с программой. Тема хранится отдельно; ключей в этих файлах нет.

Для отдельного исходного приложения, из папки app/:

```bash
python3 desktop.py --language en
python3 reprocase.py demo-all --language en
```

Для русского выберите `ru`. Параметр `--language ru|en` поддерживают также команды поиска, исторического пилота, искусственной подготовки свойства и проверки. В отдельной сборке для просмотра:

```bash
python3 -I -B judge.py gui --language en
python3 -I -B judge.py demo --language en
```

CLI без параметра использует русский; окно без параметра восстанавливает сохранённый выбор. Язык новых HTML/текстовых отчётов соответствует выбору текущего запуска. Для уже сохранённого отчёта создайте новый отчёт в выбранном языке: старый файл сам не меняется.

Перевод относится к представлению. JSON, машинные поля, хеши, исходные ответы, контексты запросов и исторические свидетельства остаются неизменными. Вкладка данных и исходный JSON предпросмотра подписаны отдельно; они могут содержать русский текст даже в режиме EN. Это точная копия данных, а не непереведённый интерфейс. Новых запросов ради перевода не требуется. Системные диалоги и сообщения Python/Tk/ОС могут использовать свой язык; настройки ОС программа не меняет.

Проверки поведения виджетов требуют доступного дисплея: `python3 -B app/localization_gui_check.py`. Код 2 означает недоступный дисплей, а не успешную визуальную проверку. При текущей приёмке Tk не подключился к `:0`; обходов и новой записи экрана не было.

Для короткого клипа: включить **EN**, нажать **Check both versions**, показать результат, затем **Test preparation preview**. Это локальные действия без API. Предыдущая запись русского окна не будет выдаваться за запись английского интерфейса.
